# Pi Pocket update notifier

An owner-only extension for [Pi Pocket](https://github.com/TannerMidd/pi-pocket) that compares the running server version with the latest published stable release and shows an update notice. It does not install updates or restart Pocket.

Requires Pi Pocket **0.16.0** and extension API level **1**.

The initial implementation is prepared in a pull request. Source, tests, and installation details will be reviewed before the gallery entry is merged.
